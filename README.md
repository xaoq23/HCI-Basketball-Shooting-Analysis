## 项目描述
1. 项目背景

- 专业指导成本高：传统篮球教学依赖教练肉眼观察，普通人缺乏专业指导，容易形成错误动作甚至导致运动损伤。
- 数据反馈不直观：普通人录下视频自己看，很难看出具体的肘部角度、发力曲线等量化指标。
- 缺乏对比与激励：缺乏与专业运动员的直观对比，容易枯燥，难以维持练习动力。
- 技术落地痛点：纯实时动态识别对手机算力要求高，且起跳落地速度快容易导致骨骼点丢失；同时投篮姿势具有主观性，不存在唯一的“满分标准”。

2. 理论支撑

- 具身认知理论 (Embodied Cognition)：强调身体动作与认知的结合，通过静态关键帧的视觉反馈（骨骼节点叠加），降低用户的认知负荷，帮助用户更直观地理解动作差异。
- 心流理论 (Flow)：通过多维度的对比交互设计（如自选球星模板、雷达图对比），给予用户明确的阶段性目标，让用户在练习中保持专注和沉浸感。
- 反馈机制 (Feedback Mechanism)：系统提供“骨骼图对比（即时视觉反馈）”+“文字/图表建议（延迟认知反馈）”，形成非评判性的辅助引导闭环。

3. 交互流程（根据降级方案优化）

```text
用户打开网页 -> 看到极简的UI（提示上传侧视角视频） -> 上传视频 -> 视频播放器加载 -> 用户通过进度条，手动拖动并截取“蓄力”与“出手”两个关键帧（解决动态识别难的问题） -> 系统对静态帧进行姿态提取，在截图上叠加彩色骨骼节点 -> 用户在下拉菜单中选择对比的“球星模型（如库里/詹姆斯）” -> 右侧生成雷达图/曲线图进行数据叠加对比 -> 系统弹出非绝对化提示（“您的出手角度与库里模型存在X度差异，发力侧重不同”） -> 用户点击保存分析报告。
```

4. 核心创新点

· 多模态交互 (Multimodal Interaction)：融合了视频输入、静态姿态视觉流、图表数据流，通过视觉与数据双重反馈，降低用户的认知负荷。
· 低成本无穿戴方案：仅需手机拍摄一段普通视频，无需昂贵的动捕设备，利用轻量级AI模型实现姿态提取，适合大众普及。
· 用户控制权增强设计 (User Control & Freedom)：将“实时识别”改为“用户手动截取关键帧”，不仅规避了高速运动下AI识别丢帧的技术瓶颈，还通过用户的操作参与，提高了分析的准确率和用户的掌控感。
· 对比可视化交互：将用户数据与顶尖球员模型进行雷达图/曲线图叠加对比，不做绝对评分，只做多维特征差异可视化，直观暴露短板。
