# 后端接口文档

面向前端同学的接口契约。后端基于 FastAPI，接口版本 `0.1.0`。

## 1. 启动与地址

```bash
cd backend
uv sync
uv run uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

- 基础地址：`http://127.0.0.1:8000`
- 健康检查：`GET /api/health` → `{"status":"ok"}`
- Swagger：`http://127.0.0.1:8000/docs`
- OpenAPI：`http://127.0.0.1:8000/openapi.json`
- 模型已随仓库放在 `backend/models/pose_landmarker_full.task`，不需要额外下载。
- 首次分析会加载模型，可能比后续请求稍慢；建议前端设置 30 秒超时。
- 开发阶段 CORS 允许所有来源的 `GET/POST`，前端可直接跨端口调用；不携带 Cookie。

## 2. 接口一览

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/health` | 探活，确认后端已启动 |
| `POST` | `/api/analyze` | 上传蓄力帧与出手帧，返回骨骼点和角度 |

## 3. POST /api/analyze

### 3.1 请求

- `Content-Type: multipart/form-data`
- 字段：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `load_frame` | File | 是 | 蓄力帧（set point），JPEG/PNG |
| `release_frame` | File | 是 | 出手帧（release），JPEG/PNG |
| `shooting_hand` | string | 否 | `auto`（默认）/ `left` / `right` |

- 两张图应来自同一段视频、同一机位；画面里只保留一个人，尽量全身入镜。
- 推荐侧视角，镜头垂直于投篮平面；角度是 2D 计算结果，会随拍摄视角变化。

### 3.2 fetch 示例

```js
const API_BASE = "http://127.0.0.1:8000";

export async function analyzeShooting(loadFrame, releaseFrame, shootingHand = "auto") {
  const form = new FormData();
  form.append("load_frame", loadFrame);
  form.append("release_frame", releaseFrame);
  form.append("shooting_hand", shootingHand);

  const response = await fetch(`${API_BASE}/api/analyze`, {
    method: "POST",
    body: form,
    signal: AbortSignal.timeout(30_000),
    // 不要手动设置 Content-Type，浏览器会自动带上 multipart boundary
  });

  const payload = await response.json();
  if (!response.ok) {
    const detail = Array.isArray(payload.detail)
      ? payload.detail.map((item) => item.msg).join("; ")
      : payload.detail;
    throw new Error(detail || `分析失败 (${response.status})`);
  }
  return payload;
}
```

`loadFrame` / `releaseFrame` 传 `File` 或 `Blob` 均可。

### 3.3 从 canvas 截帧

```js
function canvasToFile(canvas, filename) {
  return new Promise((resolve, reject) => {
    canvas.toBlob((blob) => {
      if (!blob) reject(new Error("截图失败"));
      else resolve(new File([blob], filename, { type: "image/jpeg" }));
    }, "image/jpeg", 0.92);
  });
}

const loadFrame = await canvasToFile(loadCanvas, "load_frame.jpg");
const releaseFrame = await canvasToFile(releaseCanvas, "release_frame.jpg");
const result = await analyzeShooting(loadFrame, releaseFrame);
```

### 3.5 angles 字段说明

| 字段 | 出现位置 | 含义 | 范围 |
| --- | --- | --- | --- |
| `release_angle` | `release.angles` | 小臂（肘→腕）相对水平线的仰角 | 0–90° |
| `elbow_angle` | 两帧 | 肩-肘-腕内角 | 0–180° |
| `knee_angle` | 两帧 | 髋-膝-踝内角 | 0–180° |
| `trunk_tilt` | 两帧 | 投篮侧肩-髋连线相对竖直方向的绝对夹角 | 0–90° |

- 单位：度，保留 1 位小数。
- 所有角度在像素坐标下计算，已按图片宽高修正，非方形图片不会把角度拉偏。
- `release_angle` 是二维图像上的出手方向，正面机位会失真，侧视角最准。
- 投篮侧由 `shooting_hand` 决定；`auto` 时取出手帧中手腕更高的一侧。
- 响应里的 `shooting_hand` 是最终结果，只会是 `left` 或 `right`，不会是 `auto`。

### 3.6 keypoints 字段说明

每帧返回 33 个关键点，键名固定，顺序对应 MediaPipe Pose 的索引 0–32：

```text
nose, left_eye_inner, left_eye, left_eye_outer, right_eye_inner, right_eye, right_eye_outer,
left_ear, right_ear, mouth_left, mouth_right, left_shoulder, right_shoulder, left_elbow,
right_elbow, left_wrist, right_wrist, left_pinky, right_pinky, left_index, right_index,
left_thumb, right_thumb, left_hip, right_hip, left_knee, right_knee, left_ankle,
right_ankle, left_heel, right_heel, left_foot_index, right_foot_index
```

| 字段 | 含义 |
| --- | --- |
| `x` | 归一化横坐标，0–1，相对图片宽度 |
| `y` | 归一化纵坐标，0–1，相对图片高度，向下为正 |
| `z` | 相对深度，非像素值，仅用于比较前后 |
| `visibility` | 关键点可见度，0–1 |
| `presence` | 关键点存在概率，0–1 |

- `left` / `right` 是拍摄对象的左右，不是画面左右。
- 在图片上叠加骨骼点时：

```js
const px = landmark.x * image.naturalWidth;
const py = landmark.y * image.naturalHeight;
```

- 指定侧的关键点可见度低于 0.5 时，后端不会返回半套角度，而是直接返回 422。

### 3.7 TypeScript 类型

```ts
export type ShootingHand = "left" | "right";
export type RequestedShootingHand = ShootingHand | "auto";

export interface Landmark {
  x: number;
  y: number;
  z: number;
  visibility: number;
  presence: number;
}

export interface LoadAngles {
  elbow_angle: number;
  knee_angle: number;
  trunk_tilt: number;
}

export interface ReleaseAngles extends LoadAngles {
  release_angle: number;
}

export interface FrameResult<A> {
  angles: A;
  keypoints: Record<string, Landmark>;
}

export interface AnalyzeResponse {
  shooting_hand: ShootingHand;
  load: FrameResult<LoadAngles>;
  release: FrameResult<ReleaseAngles>;
}
```

## 4. 错误响应

| 状态码 | 场景 | `detail` 形态 |
| --- | --- | --- |
| `400` | 文件为空，或不是可解码的图片 | 字符串 |
| `422` | 缺少 `load_frame` / `release_frame`，或 `shooting_hand` 非法 | 数组（FastAPI 参数校验） |
| `422` | 图片中没检测到人 | 字符串，`no pose detected...` |
| `422` | 指定侧关键点被遮挡（可见度低于 0.5） | 字符串，`landmarks not visible: ...` |
| `500` | 服务端内部异常（如模型文件缺失） | FastAPI 默认格式 |

`detail` 可能是字符串或数组，前端建议统一处理：

```js
const detail = Array.isArray(payload.detail)
  ? payload.detail.map((item) => item.msg).join("; ")
  : payload.detail;
```

## 5. curl 自测

在仓库根目录执行，把文件名换成你的两张截图：

```bash
curl -X POST http://127.0.0.1:8000/api/analyze \
  -F "load_frame=@your_load_frame.jpg" \
  -F "release_frame=@your_release_frame.jpg" \
  -F "shooting_hand=auto"
```

如果在 `backend/` 目录执行，图片路径按实际位置调整。
